DELIMOLD Native Python — TENDERLOIN

Tidak perlu memasang Python, browser, atau aplikasi tambahan.

CARA MENJALANKAN
1. Ekstrak folder TENDERLOIN ke komputer TENDERLOIN dan pertahankan susunan foldernya.
2. Klik ganda TENDERLOIN\DELIMOLD.exe.
   - APLIKASI berisi konfigurasi DELIMOLD dan katalog data awal.
   - RUNTIME berisi runtime Python portable yang dibutuhkan aplikasi.
   - Jangan memindahkan atau menghapus salah satu folder tersebut.
3. Saat pertama dibuka, pilih lokasi database lokal dan folder publikasi di SALAK.
4. Program membuat subfolder published-python di folder SALAK yang dipilih.
5. Jika database masih kosong, katalog checkpoint v12 dimuat otomatis dan program meminta pembuatan akun Supervisor pertama.
6. Untuk mengubah lokasi setelah itu, buka menu Atur lokasi data di sidebar sebagai Supervisor.

Jangan hapus atau timpa database kantor yang sudah berisi data. Database lokal disimpan di %LOCALAPPDATA%\DELIMOLD\delimold.sqlite3.

Jika aplikasi gagal mulai, periksa %LOCALAPPDATA%\DELIMOLD\startup.log.

Paket ini berfokus pada pembukaan aplikasi utama di TENDERLOIN. Tidak ada file BAT di dalam paket. Mode Engineer akan disiapkan setelah aplikasi utama berhasil dibuka.

Seed checkpoint berisi 869 cetakan, 108 container, dan 89 pattern; seed tidak berisi akun lama, project aktif, atau pembelian live.
