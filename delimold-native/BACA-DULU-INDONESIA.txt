DELIMOLD Native — TENDERLOIN Master dan SALAK Viewer

Tidak perlu memasang Python atau aplikasi tambahan.

PERSYARATAN
Windows 7 SP1 x86. Paket menggunakan Python 3.8.10 32-bit, PyInstaller 6.0.0, dan menyertakan Universal C Runtime x86.

PEMASANGAN PAKET
1. Ekstrak folder TENDERLOIN ke komputer data TENDERLOIN.
2. Salin isi folder SALAK ke lokasi share SALAK. Pertahankan folder published di samping DELIMOLD-Viewer.exe.
3. Jangan gabungkan atau memindahkan isi folder RUNTIME. Setiap EXE memakai runtime portable yang ada di folder paketnya.

MEMULAI DI TENDERLOIN
1. Buka TENDERLOIN\APLIKASI\Pilih-Published-SALAK.exe.
2. Pilih folder published yang sudah ada pada share SALAK, lalu klik Simpan lokasi.
   Pemilih menyimpan pilihan di %LOCALAPPDATA%\DELIMOLD\config.json. Pemilih tidak membuat folder SALAK.
3. Buka TENDERLOIN\APLIKASI\DELIMOLD.exe.
4. Buat akun Supervisor pertama. Sesudah akun berhasil dibuat, katalog awal akan dimuat.

MEMBUKA VIEWER DI SALAK
Jalankan SALAK\DELIMOLD-Viewer.exe. Viewer hanya membaca SALAK\published\catalog.json, tidak membuka database TENDERLOIN, dan tidak menyediakan aksi edit. Viewer menampilkan snapshot terakhir yang berhasil diterbitkan; TENDERLOIN tetap menjadi sumber data utama.

DATA
Database akun dan data master berada di TENDERLOIN\DATABASE\delimold.sqlite3. Jangan menghapus folder DATABASE saat memperbarui aplikasi. Folder SALAK\published berisi snapshot baca-saja yang dibuat oleh TENDERLOIN saat publikasi pertama berhasil.

Jika share SALAK sedang tidak tersedia, data lokal di TENDERLOIN tetap dapat digunakan. Publikasi dicoba kembali saat koneksi pulih. Jika aplikasi gagal mulai, periksa %LOCALAPPDATA%\DELIMOLD\startup.log.
